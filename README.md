# Electrolab — Física interactiva

Laboratorio de electricidad y magnetismo con las cuatro unidades, escenas 3D, editor de circuitos, energía animada y video de funcionamiento.

## Uso

Abre el enlace de GitHub Pages del repositorio desde una computadora, tableta o celular. El menú permite explorar cargas y potencial, capacitores, circuitos y magnetismo. Manual, informe, presentación y video están en la navegación superior.

Cada visitante conserva su propio circuito en el almacenamiento de su navegador. Guardar JSON permite trasladarlo a otro dispositivo. No se requieren cuentas para usar el simulador publicado.

La versión web incluye el video MP4 de 6:24. La creación de nuevas grabaciones requiere Chrome o Edge y mantener visible la pestaña.

## Publicación

Los archivos estáticos se sirven desde la raíz de la rama main mediante GitHub Pages. .nojekyll permite publicarlos sin procesamiento adicional. La biblioteca Three.js incluida conserva su licencia en THREE-LICENSE.txt.
